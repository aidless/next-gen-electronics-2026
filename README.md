# README — 新一代电子技术前沿与产业格局研究

## 目标

系统梳理"新一代电子技术"（材料→器件→架构→系统→产业）2024–2026 前沿进展与产业格局，形成可引用、可追溯、可增量更新的研究合集。对每条主线给出成熟度分层与 12–24 个月可证伪观察指标。

## 核心问题

AI 算力需求与物理约束（制程放缓、存储墙、互连带宽、电力）叠加下，"新一代电子技术"在哪些方向已规模兑现、哪些仍处实验室、未来 2 年确定性最高的卡点在哪。

## 三层框架

材料 → 器件 → 架构（+系统层）。依据双清论坛综述（https://doi.org/10.1360/SSI-2025-0056）与中科院学部光电融合报告（https://academics.casad.cas.cn/zlyj/qyjcyp/202507/t20250726_5077855.html）。

## 证据纪律

- 结论先行；每个数字附出处链接与日期。
- 论文 DOI 经 web_fetch 验号（号-题-出版日）；未取一手源标 `UNVERIFIED`，不入结论。
- 市场预测注明机构与口径，冲突并列不混用（如 2026 半导体市场 $975B–$1.655T、CoWoS 12–14 万 vs 12.5 万片/月）。
- 冲突数据并列标注，读者自行判断时点。

## 数据来源

公开源为主：标准组织（3GPP/IEEE）、官方发布（WSTS/SIA/BIS/Federal Register）、同行评议综述、权威产业媒体（TrendForce/Yole/IDTechEx/SemiAnalysis）、企业新闻稿（交叉核验后使用）。原始数据不入 git（data/ 已排除）。

## 运行 / 更新方式

- 增量更新流程：对每个专题唤醒对应子代理做"只增不改旧数字"的增补，强化"方向判断/共识边界"节，再重跑统一自检（表格列数/空行/围栏/占位符）与合集重生成。
